# StudyHub Pro

A modern digital library built with React and Vite.

## Features

* Search notes instantly
* Clean Notion-inspired UI
* Responsive design
* Modern React component architecture

## Tech Stack

* React
* Vite
* JavaScript
* Framer Motion
* React Icons

## Installation

```bash
npm install
npm run dev
```
